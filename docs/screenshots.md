# Screenshot Placeholders

Store screenshots in `docs/screenshots/`. This directory is for repository documentation and is not included in the packaged extension build.

Add these files before publishing to the Chrome Web Store:

| View | File |
| --- | --- |
| Product page stock checker | `docs/screenshots/product-page-stock-checker.png` |
| Product page stock detail panel open | `docs/screenshots/product-page-stock-panel.png` |
| Category page inline stock cards | `docs/screenshots/category-page-stock-cards.png` |
| Settings page default store selector | `docs/screenshots/settings-default-store.png` |
| Unavailable/error state | `docs/screenshots/unavailable-stock-state.png` |

Recommended final screenshot size for Chrome Web Store listing assets should follow the current Chrome Web Store image requirements.
